features:
  - title: 三种内容
    details: 动态壁纸铺满一块显示器，也能跨多块；小组件贴在桌面上或浮于窗口之上；桌面伙伴陪在所有窗口之上。
  - title: 熟悉的 API
    details: Canvas 2D、WebGL 2、fetch、WebSocket、Web Audio 和 Streams，three.js 和 PixiJS 可以直接用。
  - title: 一条命令调试
    details: desktopengine dev 在应用里运行项目，保存即重载，console 和异常显示在终端里，还能用 Safari 断点调试。
  - title: 应用负责其余的事
    details: 选项表单、权限询问、多显示器、深浅色、暂停和省电规则都由应用统一处理，内容只管画。
  - title: 在浏览器里试
    details: desktopengine dev --web 在一个像 Mac 桌面的网页上运行内容，和商店让人在安装前试用内容的是同一个网页运行时。
  - title: 发布到商店
    details: desktopengine publish 把内容发布到 DesktopEngine 商店。每个版本都经过审核，用户从商店安装，并自动收到你的更新。
